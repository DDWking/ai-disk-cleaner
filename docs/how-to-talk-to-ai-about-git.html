如何跟 AI 沟通 Git

给队友的 5 分钟交接 · 核心就一句：把状态告诉 AI

1. 每次提问，先给 AI 三样东西

  • ① 当前分支：我在 feature/mft-scan 分支
  • ② 你想做什么：我想把改动合并回 main
  • ③ 粘贴 git status 和 git log --oneline -5 的输出
AI 看不见你的屏幕。你不贴状态，它只能瞎猜。

2. 常用提问模板（直接抄）

写 commit：我改了 scanner.py，实现了读取文件路径和大小，请写一条规范的 commit message。
解冲突：我和队友都改了 scanner.py，冲突了。我的意图是 [A]，对方是 [B]，帮我分析每段保留哪边并解释。
写 PR 描述：帮我把 feature/xxx 相对 main 的改动整理成 PR 描述：做了什么、怎么测、有什么风险。
看懂命令：网上说执行 git reset --hard HEAD~1，请解释它会删掉什么，有没有更安全的替代。

3. 红线：别让 AI 直接执行，也别盲从

git push --force  git reset --hard  git checkout .  git clean -fd
约定：让 AI 逐条解释命令，自己看懂再敲。带 --force / --hard / clean 的，先问一句"会不会丢东西"。

4. 交接清单（给队友 / AI / 未来的自己）

  • 分支：feature/xxx
  • 我做了什么：……
  • 还没做完：……
  • 卡在哪：……
  • 下一步建议：……
